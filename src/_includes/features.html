Why Choose psmux?

🪟

Native Windows

Built specifically for Windows 10/11. No WSL, no Cygwin, no compromises. Works perfectly with Windows Terminal, PowerShell, and cmd.exe.

⚡

Zero Dependencies

Single binary that just works. Download and run - that's it. No complex setup or additional software required.

🎯

tmux Compatible

Same commands, same keybindings, zero learning curve. Use your existing tmux muscle memory on Windows.

🔧

Multiple Aliases

Use psmux, pmux, or tmux - they're all identical. Choose the command that feels right for you.

🖱️

Mouse Support

Full mouse support for resizing panes and navigating windows. Intuitive and user-friendly.

📜

Scrollback History

1000 lines of scrollback history per pane. Never lose important terminal output again.
